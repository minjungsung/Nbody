# Nbody

N-body 중력 시뮬레이션 프로젝트입니다. 태양과 행성들의 궤도를 물리 시뮬레이션(`rebound` 라이브러리)으로 생성하고, LSTM 신경망을 학습시켜 천체의 위치와 속도를 예측합니다.

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **언어** | Python 3.x |
| **물리 엔진** | rebound (N-body 시뮬레이션) |
| **딥러닝** | PyTorch (LSTM 모델) |
| **데이터 저장** | HDF5 (h5py) |
| **시각화** | Matplotlib |

## 물리적 배경

### N-body 문제란?

N-body 문제는 N개의 천체가 서로의 중력에 의해 어떻게 움직이는지를 계산하는 고전 역학 문제입니다. 뉴턴의 만유인력 법칙에 따라 각 천체는 다른 모든 천체로부터 중력을 받습니다.

```
뉴턴의 만유인력 법칙:
F = G × (m₁ × m₂) / r²

여기서:
  F  = 중력
  G  = 중력 상수
  m₁, m₂ = 두 천체의 질량
  r  = 두 천체 사이의 거리
```

### 시뮬레이션 구성

이 프로젝트에서는 3-body 시스템을 시뮬레이션합니다:

| 천체 | 질량 (m) | 궤도 반지름 (a) | 역할 |
|------|---------|----------------|------|
| 천체 0 | 1.0 | — (중심) | 태양 |
| 천체 1 | 0.001 | 1.0 AU | 행성 1 |
| 천체 2 | 0.001 | 1.5 AU | 행성 2 |

```
       ★ 태양 (m=1.0)
      /     \
     /       \
    ●         ●
 행성1       행성2
 (a=1.0)    (a=1.5)
```

## 핵심 아이디어

물리 시뮬레이션 데이터를 딥러닝(LSTM)으로 학습하여 **시뮬레이션 없이** 천체의 미래 위치를 예측합니다.

```
Traditional Approach:
  초기 조건 → 수치 적분 (매 시간 스텝) → 위치 계산

ML Approach (이 프로젝트):
  과거 위치 시퀀스 → LSTM 모델 → 다음 시간 스텝 위치 예측
```

## 프로젝트 구조

```
Nbody/
├── nbody.py              # 1. N-body 시뮬레이션 & 데이터 생성
├── predata.py             # 2. 학습 데이터셋 전처리
├── model_definition.py    # 3. LSTM 모델 정의
├── inference.py           # 4. 모델 학습 (추론/훈련)
├── result.py              # 5. 결과 시각화
└── .github/workflows/     # CI
```

## 기술 스택 상세

```

h5py             → HDF5 데이터 저장/로드
numpy            → 수치 연산
matplotlib       → 결과 시각화
```
